# Worksheet Helper

React + JS app for children. Upload a worksheet photo, answer it on screen, get the score and grade.

## Run
1. `npm install`
2. Copy `.env.example` to `.env` and put your key: `VITE_API_KEY=...`
3. `npm run dev`

## Note
The key is used in the browser (no backend), so anyone technical can see it.
Set a small spend limit on it, and move the API call to a serverless function before a public launch.
